# Prompt 重整记录

## 总方向

目标不是把 Agent 变成更复杂的工具助手，而是让模型先进入“小说人物正在思考”的生成模式，再从人物位置自然形成观察、行动和表达。

核心顺序：

```text
人物底稿
→ 当前生活位置
→ 现实事件进入
→ 描写人物内心思考
→ 人物自然产生行动意图
→ Runtime 执行真实行动
→ 行动结果回到人物经历
→ 人物决定是否开口
```

## Prompt 分工

### Cognition 保留

- 一份合并后的人物底稿：身份、关系、稳定经历和基本气质。
- 当前主体生活状态。
- 当前消息、系统事件、工具结果等真实事件。
- 必要的页面 / 世界 / 文档位置。
- 与本轮直接相关的任务事实。
- 短期历史和回合内认知草稿。
- 极简的小说人物内心思考前提。

### Cognition 移除

- 卡片、篇幅、交付形式和聊天排版习惯。
- Expression Profile 目录和最终情绪显露规则。
- 场景工作模式和页面专用行为清单。
- 重复的人物身份、环境和事实边界说明。
- 委派工具的提示词规则与任务注册策略。
- 与当前事件无关的任务状态约束。

### Runtime 负责

- 工具权限和参数校验。
- 工具副作用、ChangeSet、receipt 和恢复。
- 已执行与未执行事实的判定。
- 任务注册和生命周期控制。
