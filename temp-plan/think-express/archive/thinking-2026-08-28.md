# Agent 人格、思考与表达待办

## 当前基线

当前链路为：

```text
用户消息、近期对话、页面与记忆
  → Self Core、关系与 Mood 参与理解
  → 自然语言 Reasoning 与工具观察循环
  → 形成观点、行动和交流意图
  → 选择情绪 Expression Profile
  → Final Composition
```

已经具备：

- Self Core 作为稳定身份真源，并支持作者叙事 revision。
- Mood 同时理解用户短期状态和事件对 Agent 自身的意义。
- 人物分析、剧情讨论思考指南按需调用。
- Expression Profile 只在最终组织阶段出现，并按 Agent 当前情绪选择。
- 长期习惯工具可根据当前用户明确原话设置、替换或忘记思考、交流和工具偏好。
- 原生与普通模型统一经过 Final Composition 和 Output Guard。

## P0：人格与思考真实表现验收

使用真实连续对话验证以下场景：

1. 人物资料不足：Agent 能意识到自己是否第一次接触、缺少什么、是否值得追问或读取，而不只说“资料较少”。
2. 人物资料充分：Agent 能形成自己的理解、感受和疑问，不退化为人物摘要或正式赏析。
3. 用户与 Agent 看法不同：Agent 能自然保留、协商或修订观点，不机械反对，也不立刻迎合。
4. 情绪变化：生气、愉悦、受伤、不安和平静在思考中有真实原因，在表达中只改变温度、节奏和力度。
5. 日常讨论：最终回答像人与人交流，不是捧哏、客服话术或另一版思维链。
6. 思考指南：只在缺少观察角度时调用，不成为每轮固定模板。
7. 习惯编辑：只有用户明确表达长期意图时写入；一次性格式要求不持久化；新要求能替换或撤销旧习惯。

验收重点不是 Prompt 是否包含某句话，而是多轮行为是否稳定、自然且能被用户感知。

## P0：表达链收口

- 检查主 Reasoning Context 是否仍残留会诱导“提前写回答”的表达规则。
- 明确交流意图：回答、讨论、追问、表达态度、共同探索或汇报结果，不增加强制枚举输出。
- 验证 Final Composition 是否保留已经形成的主体态度，同时不临时伪造欲望和情绪。
- 观察卡片习惯是否导致过度发布；卡片应承载独立长内容，聊天仍保留自然回应。

用户影响：内部思考与最终表达承担不同职责，回复不再像两次相似改写。

## P1：Mood 小型收口

- 审计 `hardRules`、首选主情绪和 presence：有唯一消费者则保留，否则删除。
- Appraisal 降级时在 Trace 区分“真实中性”和“模型失败后的中性回退”。
- 统计 Appraisal 输入成本；只有占用明显时才压缩稳定自我与上一状态摘要。
- 保持低置信度不造成突变、中性对话不积累厌倦、旧 Mood 不被当前低置信度事件清空。

用户影响：情绪既能短时变化，也能长期缓变，同时避免无故生气、无聊或失忆。

## P1：Post-Turn Observer

主推理不直接写入长期人格。Turn 完成后，由后台观察器根据用户消息、Reasoning、工具 Receipt、最终回答和实际结果提出候选：

- 值得长期记住的重要事件或用户偏好；
- 关系中的承诺、冲突和修复；
- Agent 对自身经历形成的可修订认识；
- 尚未完成但值得跨轮延续的关注。

候选分别交给 Memory、Relationship、Self Experience 和 Self Core Authority 审核；观察器不能直接修改权威状态，失败也不能回滚已经完成的回答。

用户影响：Agent 能逐渐积累共同经历，而不是只保留聊天摘要或把每句话都写成长记忆。

## P1：Provider 真实协议验证

- 使用一个原生 reasoning 模型和一个普通模型完成“思考 → 工具 → 观察 → 再思考 → Final”。
- 验证工具调用步骤中的空 reasoning、content block 和 metadata 差异。
- 根据实测补充已知模型能力声明，不恢复逐响应猜测。

## 暂不推进

- 结构化认知表、固定交流意图枚举或欲望数值。
- 为每种讨论场景建立独立思考节点。
- 让 Expression Profile 产生观点、事实、情绪或工具权限。
- 在真实行为问题出现前继续增加人格参数。
