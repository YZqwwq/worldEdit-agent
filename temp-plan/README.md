# Agent 后续计划索引

## 使用方式

本目录只保留三类文档：总路线图、当前缺陷和专题设计。开始工作时先读总路线图，再按当前任务进入对应专题；专题中的历史实施记录不能覆盖总路线图的当前决策。

## 权威顺序

1. `future-roadmap.md`：唯一执行入口，记录当前优先级、阶段顺序和完成标准。
2. `future-lack.md`：记录尚未闭环的问题及其用户影响，不承担详细实现设计。
3. 专题文档：解释一个边界内的设计和验收方式。

发生冲突时，以上方文档为准；专题文档应随总路线图同步修订。

## 当前决策

- 不再提供暂停并继续同一个 Turn；用户运行中控制统一为中断。
- 中断直接终结当前 Turn，封存完整 Workspace，但只发布已经闭合的稳定影响。
- 中断提交成功后当前消息离开调度集合并释放执行槽，不重新入队。
- 崩溃恢复属于 Turn Version 的持久化重建流程，与用户主动中断分开设计。
- 当前先完成中断提交闭环，再独立修订崩溃恢复。
- 有副作用工具后续统一接入 `ChangeSet + EffectReceipt`：业务存储保留最终事实，Receipt 记录动作结果，ChangeSet 聚合同轮或同任务的多个动作。
- 当前 `durableToolReceipts` 是该记录层在 Workspace 中的稳定投影；第一阶段只以世界文档验证，不建设全工具虚拟文件系统，也不要求所有工具一次迁移。
