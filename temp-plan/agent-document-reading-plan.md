## 当前基线

- 文档已与人物、国家、地域、种族等实例完全解耦，只归属于世界观。
- 文档可以在世界内自由创建根节点和任意树结构；应用不维护文档与概念实例的关联。
- 当前页面上下文仍可向 Agent 提供正在查看的世界、文档 ID、标题和 revision，因此已知当前文档可以被精确读取和编辑。
- 现有 `read_world_document` 可以按文档 ID 返回完整 Markdown 与章节信息；现有全量文档列表不适合承担大规模发现。

## 解耦后的边界影响

- 人物印象等旧能力不能再通过人物实例直接圈定“所属文档”；按人物世界 ID 读取会错误覆盖整个世界文档库。
- Agent 在只知道名称、简称或描述时，必须先从世界文档中发现候选，再决定对象相关文档。
- 文档标题和目录只提供线索，不代表固定语义类型；工具不得自行断言某篇文档属于人物、国家或地域。
- 概念即使没有对应应用实例，也应能够被 Agent 发现和认识。
- 当前文档 ID 的直接注入继续保留，但它只表达用户正在查看的文档，不代表用户询问的对象只存在于该文档。
- 文档版本、Diff、恢复和编辑能力继续以世界文档树为边界，不依赖概念认知缓存。

## P0：稳定发现与阅读

状态：已完成。真实文档语料暂时不足，因此召回权重只保留后续真实数据验收，不阻塞认知缓存开发。

建立三个职责单一的基础工具：

1. `search_world_documents`
   - 输入世界 ID、查询文本和可选结果上限。
   - 混合精确子串、中文词边界、2/3 字片段和字段化 BM25，搜索标题、文档路径与正文可见文本。
   - 支持名称片段和自然多关键词；精确标题保持最高优先级，BM25 负责扩展召回和相关性排序。
   - 每篇文档只返回一个最相关正文片段，同时返回标题、文档 ID、路径、revision、命中字段、命中词、完整短语出现次数和综合分数。
   - 返回 `totalMatches` 与 `hasMore`；默认 10 条、最大 30 条，结果过多时应细化查询。
   - 按世界维护最多四份运行时 LRU 索引；正文、标题或树路径变化后自动失效，同 revision 或同长度改写也不会复用旧索引。

2. `browse_world_document_tree`
   - 不传根文档时返回世界根节点及其下一层。
   - 传入根文档时返回该节点及向下两层结构。
   - 节点只包含结构信息，并明确提供 `childCount`、`hasMoreChildren` 和可继续浏览的文档 ID。
   - 根文档不属于指定世界时返回包含修正建议的结构化错误。

3. `read_world_document`
   - 已知文档 ID 时返回完整 Markdown、revision、元数据和章节结构。
   - 现有按标题章节读取能力作为大型文档的进阶入口保留，不承担首次发现。

现有一次性返回全世界扁平文档列表的 Agent 入口由渐进树浏览取代，避免重复能力和无关上下文膨胀。工具集说明只声明选择原则：未知对象先搜索，已知目录按树浏览，已知文档直接读取；不强制固定调用流水线。

检索与树浏览内核位于 worldbuilding 领域层，Agent 工具只负责参数、UI 阶段和上下文投递。后续更换 Graph、Runtime 或工具注册机时不得把领域检索重新耦合回 harness。

### P0 验收

- 能通过完整名称和名称片段找到标题候选。
- 能找到只在正文中出现或分散出现的查询词，并返回关键词最集中的相关片段和完整短语出现次数。
- 搜索和树浏览不会跨世界泄露文档。
- 能从世界根节点逐次浏览到深层文档，并知道哪些节点尚未完全展开。
- 搜索结果有明确上限，空结果和错误参数都有可执行反馈。
- 已知当前文档时可直接读取，不产生多余搜索调用。

## P1：Agent 世界认知缓存

持久化、最小工具闭环、来源失效与文档发现接入已经完成，详细边界和后续阶段统一记录在 `cognitive_world_domcment.md`。当前下一步是让人物印象等上层能力利用认知选择阅读入口，不再重复设计认知表与基础工具。

认知对象至少记录：

- Agent 判断的概念类型；类型允许开放扩展，不限定为人物、国家或地域。
- 规范名称与用户惯称、简称、别名。
- 作为主要入口的根文档 ID，以及其他相关文档 ID。
- 判断依据、置信度、最近验证的文档 revision 和更新时间。

基本流程：首次遇到未知称呼时广搜候选，必要时浏览目录并读取正文；确认对象后记录称呼与文档入口。后续再次出现简称时先命中认知缓存，但在文档 revision 变化、候选冲突或低置信度时重新搜索验证。

认知缓存不是事实数据库，也不自动创建人物或国家实例。错误认知必须可修正，来源文档删除、移动或内容变化后不得静默沿用失效结论。

### P1 实施顺序

1. 已完成：世界级、开放维度的认知空间、统一节点与来源证据。
2. 已完成：按世界和名称查询，以及新增、修正和 revision 校验工具。
3. 已完成：认知命中已接入 Agent 文档搜索；有效认知提高候选优先级，待验证认知不会压制普通搜索。
4. 已完成：文档 revision 变化或来源删除时，关联认知在同一事务中进入待验证，不直接删除历史认知。
5. 下一步：让人物印象阅读等上层能力通过认知记录选择文档范围，移除按人物实例读取整个世界文档的错误路径。

第一版只做可追溯、可修正的最小闭环。不要同时引入向量数据库、自动实体创建、固定概念类型枚举或复杂知识图谱。

### P1 验收

- 首次询问简称时能够通过广搜定位完整对象。
- 再次使用同一简称时能够复用认知，同时保留来源可追溯性。
- 同名对象不会被无提示合并；证据不足时保留多个候选。
- 文档 revision 改变或根文档删除后，相关认知会进入待验证状态。
- 人物印象阅读等上层能力通过认知结果确定阅读范围，不再依赖实例归属字段。

## 暂不处理

- 第一版不做错别字纠正、向量语义搜索或自动实体创建。
- 第一版不让搜索工具判断概念类型，也不让认知缓存反向约束用户的自由目录结构。
- 在真实语料验证前不引入向量检索、同义词模型或持久化索引表；当前运行时混合索引保持工具合同稳定，后续只按规模和召回数据继续演进。
