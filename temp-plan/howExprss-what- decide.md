# 哪些维度决定 AI 怎么想，并进而影响怎么说

```text
现实信息 → 人格化理解与思考 → 形成观点和交流意图 → 情绪化表达 → 最终回复
```

## 决定怎么想

| 维度 | 设计初衷 | 预期效果 |
| --- | --- | --- |
| 当前消息与近期对话 | 理解用户此刻真正想谈什么，并保持话题连续。 | 不答非所问，也不会每轮重新开始。 |
| 长期记忆与关系 | 延续共同经历、用户特点和关系变化。 | 像长期伙伴，而不是无状态助手。 |
| 稳定人格 | 决定 Agent 长期在意什么、如何判断和采取行动。 | 形成稳定关注点和独立立场，而不只是固定语气。 |
| Mood 与用户状态感知 | 让当前感受影响注意力、事件解释和回应倾向。 | 情绪先参与思考，最终表达才会自然可信。 |
| 页面与任务状态 | 让 Agent 知道自己正处于什么工作环境、面对什么对象。 | 在编辑、讨论或检查时采用合适的思考深度与工具倾向。 |
| 世界认知、记忆与工具证据 | 提供对人物、地区、文档及执行结果的真实认识。 | 分清已知、推测和未知，减少臆造与重复查询。 |
| 按需思考指南 | 在需要时补充人物分析、剧情讨论等观察角度。 | 帮助 Agent 深入思考，但不把思考固化成模板。 |

这些维度最终应形成：**关注点、个人观点、不确定之处、下一步行动和交流意图**。

## 决定怎么说

| 维度 | 设计初衷 | 预期效果 |
| --- | --- | --- |
| 思考结论与交流意图 | 决定这次真正要告诉用户什么，以及是回答、讨论、追问还是表达态度。 | 最终回复有内容目的，不是对思维过程换一种说法。 |
| 稳定表达底色 | 保持 Agent 长期一致的语言习惯和关系质感。 | 不同情绪下仍像同一个人。 |
| 情绪 Expression Profile | 根据已经形成的平静、愉悦、生气、悲伤等情绪调整表达。 | 情绪通过措辞、节奏和力度自然显露。 |
| 用户要求与内容载体 | 适配篇幅、格式、聊天、文档或卡片等实际需求。 | 人格表达不妨碍任务完成和内容阅读。 |
| Final Composition | 最后组合观点、态度和表达方式。 | 输出像真实交流，不泄漏内部思考或工具过程。 |

## 边界

- Runtime 只决定模型资源，不决定人格、观点和情绪。
- 安全与工具权限只约束能否执行，不决定 Agent 应该怎么想和怎么说。
- Expression 只呈现已经形成的情绪与认识，不反过来制造它们。
