# Agent 世界文档与认知待办

## 当前基线

- 世界文档只归属于世界，不再与人物、国家、地区等实例强绑定。
- Agent 已具备搜索、渐进树浏览和按章节/全文阅读能力。
- Scene/WorldFocus 已移除；主 Agent 根据当前问题是否依赖事实，自主决定是否搜索和阅读。
- 世界认知使用 Agent 自己建立的维度与概念卡片，保存名称、别称、摘要、来源文档和 revision。
- 人物印象通过认知记录确定阅读范围，不再读取整个世界文档库。
- 工具结果通过统一 Tool Evidence 向同一 Turn 后续步骤传递对象引用。

## P0：真实世界认知验收

用真实人物、国家、地区和势力完成以下连续场景：

1. 第一次提到未知对象时，Agent 能按需搜索候选并在必要时阅读正文。
2. 已有认知卡片时，Agent 能先获得模糊印象，再决定是否需要读取原文。
3. 工具确认对象后，后续步骤沿用名称、类型、对象 ID 和世界 ID，不重复搜索。
4. 同名或低置信度候选不会被静默合并，也不会伪造确定对象。
5. 只做命名、假设讨论或自由创作时，不因缓存缺失被迫查询。
6. 获得足够证据后，Agent 能自主判断是否值得保存或更新认知；普通读取不自动持久化。
7. 文档 revision 改变或来源删除后，旧认知进入待验证，并能重新确认。

用户影响：Agent 对世界既有逐渐形成的印象，也保留查证和自由创作的弹性。

## P1：认知与证据边界加固

- 实体工具显式声明哪些结果是“已确认引用”；通用递归提取只作为兜底，搜索候选和输入回显不能进入确认引用。
- 保存或移动认知节点时检查完整祖先链，禁止形成循环。
- 认知空间 revision 使用数据库原子递增，避免连续或并发保存丢失变更标识。
- 认知服务异常回退普通文档搜索时写入内部 Trace，但不向用户泄漏内部故障。
- 验证人物印象与通用世界认知职责：认知负责对象导航和来源入口，人物印象负责对具体人物的综合主观看法。

## P1：规模与 Context 成本

先记录再优化：

- 搜索候选数量、读取正文长度、认知卡片命中率和重复搜索率。
- Tool Evidence 中对象引用与正文摘要各自占用。
- 100、1000、10000 文档规模下搜索、目录浏览和缓存刷新延迟。

只有真实数据表明需要时，再考虑全文索引升级、认知树浏览、同义词模型或向量检索。

## 暂不推进

- 固定“人物、国家、地区、势力”等数据库维度枚举。
- 自动创建世界实例或自动把每次阅读写入认知。
- 为每类对象恢复独立 Focus 节点。
- 在没有规模数据前引入知识图谱或向量数据库。
